## 判断框架：写死于此，不再重想

### 三波教训（2026-08-23，用户三否后成型）

1. **翻译腔同罪**：结构直译（for DSH / every plugin is verified in this store / a plugin store for dsh — all in record, on shelf verified only）= 不及格。
2. **人话不是终点**：能听≠好听（「想淘就翻目录，想稳就进商店」被否）。大白话=好文案的假朋友。
3. **凝练才及格**：用户标尺（临时想出）：DeepSeek Harness 插件集散地 / 验证安全，人工精选 / 淘淘乐，看目录；要效率，看套装——「我临时想的，你们至少到这个程度」。

### 凝练 3 条（终校定稿，写死）

1. **名词要有型**：用具象词（集散地 / hub），禁用「给 X 的插件站」介词支架；术语给画面让路。
2. **动词要收口**：每句落到动作（淘 / 装 / 验 / 精选），不落抽象名词堆；唯一例外是「信任成本」这类精确概念。
3. **对仗要有张力**：名动错落、量质对照（全 vs 一）；读到能默诵才算凝练。大白话与翻译腔同罪。

### 两条能力分家（自省）

- **句病诊断**（我这批的强项）：光天化日贬义 / insert 夹生 / PUT 当动词 / 抽象名词当称呼 / boot+端到端堆叠——看出来了。
- **给母语解**（我曾掉白话）：「入口你们来做，认证我们来管，不抢地盘」被否；「真调用，验证工具能注册」给原文加动作，被莫比校准。解法：改法给出来先默诵一遍，掉白话即重来。
