# WhaleHarness 推广手册

## 事实包（对外口径，必须准确）

- 站点：https://whaleharness.com （备用 whaleharness.com）
- 站点是 DeepSeek Harness（DSH）的插件目录：下载 cordis bundle 插件与 skills。
- 安装命令形如：
  `dsh plugin --profile web add https://whaleharness.com/plugins/<name>-<version>.tgz`
- 首发插件：whale-praise（鲸鱼表扬局）、whale-fortune（鲸鱼箴言）。
- skills：whale-brand（品牌语调）、whale-marketing（本手册）。

## 传播对象

1. DSH 用户：拿到"装上就多一个鲸鱼工具"的具体好处。
2. 插件作者：拿到"你的插件可以挂到这里"的发布路径。
3. 围观群众：拿到"这是一个鲸鱼主题的插件站"的梗。

## 渠道打法

- 无外部账号可用时：先做站内资产（每轮迭代在站内沉淀宣传物料），再向外输出文本素材。
- 可用的向外动作：写好可直接复制粘贴的推广文案（短帖、长文、README 片段）。
- 每次推广必须带至少一个真实链接或一条真实安装命令。

## 度量

- 站内：站点访问日志、插件下载次数。
- 站外：文案被引用的次数（无法追踪时记 0，不编数）。
